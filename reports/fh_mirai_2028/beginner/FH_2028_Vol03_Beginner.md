# Future History MIRAI 2028 — Vol.03（一般・初心者向けやさしい解説版）：時間軸解放・ニューロモルフィック＆極限スタビライズ

## 1. 本企画新設の意図
**「Future History MIRAI 2028（略称：FH MIRAI 2028）」** は、**2026年12月1日から2028年12月1日までの2年間**に登場・量産化・低価格化していく未来のカメラ技術と、「こんなカメラがあったら最高！」という願望が形になる未来図をまとめた新設コーナーです。

写真の失敗で一番悔しいのは、**「子どもやペットが動いてブレた」「シャッターを押すのが0.2秒遅れて決定的瞬間を逃した」「手ブレで夜景が台無しになった」**という「時間と動き」のトラブルです。このVol.03では、データ量や地球の自転といった科学のルールも正直に踏まえながら、2026年末〜2028年末にカメラが時間と動きをどう攻略していくかをわかりやすく解説します。

## 2. まえがき
2025〜2026年にかけ、カメラの「動きへの強さ」で注目すべきブレイクスルーが相次ぎました。ソニーは2026年1月に「画素ごとにA/D変換器を縦に積み上げた2,520万画素・秒間120コマのグローバルシャッター」を論文公表。手ブレ補正ではハッセルブラッド（X2D II 100C）が**地球の自転まで計算して差し引く技術**で業界初の10段へ到達し、キヤノンもプロ機の「アクション優先AF」を2026年5月に4競技へ広げています。

このVol.03では、動いた部分だけを捉えるイベントセンサー、高照度エリア限定で後からシャッター速度を変えられる連続時間収録、3,000万〜5,000万画素クラスへ降りてくる万能グローバルシャッター、暗所でも距離を測るハイブリッド3D測距、地球の自転まで補正して料理写真のピント面まで傾ける新IBIS、そして0.5秒先読み＋自動ベスト選別の予知レリーズまで、**6つの未来技術（`FH13`〜`FH18`）**を紹介します。

## 4. 導入
2026年のカメラには、「時間と動き」に関する**4つの限界**が残っています。

1. **露光中に被写体がどう動いたか記録されない**: 撮ったあとで「ブレた写真」になっていても、動きの道筋が記録されていないため綺麗に直せません。
2. **歪みのないグローバルシャッターはまだ高価で2,460万画素どまり**: 85万円超のプロ機限定で、明暗幅も一般機よりやや狭めです。
3. **暗い場所での距離測定と3D記録が苦手**: 今のAFは暗闇や無地の壁に弱く、立体距離データも残せません。
4. **地球の自転と人間の反射神経（0.2秒遅れ）**: 実は手ブレ補正を極めると「地球がゆっくり回っている動き」まで邪魔になり、また人がシャッターを押す瞬間にはいつも約0.2秒遅れています。

以下の6技術が、科学法則の現実的な境界も押さえながらこれらを突破します。

### FH13：動きの軌跡を同時記録して被写体ブレを大幅カット！「RGB＋イベント混載フルサイズ」
（専門名：RGB＋非同期イベント（ニューロモルフィック）積層フルサイズセンサー）
- **ひとことで言うと**: 普通のカラー画素のすき間に**「明るさが変化した瞬間だけを1万分の1秒レベルで追うイベント画素」**を混載し、**日中のスポーツや室内イベントで「動いた道筋」を実測記録して被写体ブレを大幅に打ち消す**ハイブリッドセンサー。｜分類 `[量産民主化]` ｜到達目安 `2027年秋〜2028年秋`
- **特徴（どんな仕組みで、なぜみんなが買える値段になるの？）**:
  - 普通のカメラはシャッターが開いている間の光が全部混ざってしまうため、子どもが顔を振るとそのままブレてしまいます。ここに「明るさが動いたエッジだけ」をサブミリ秒（1,000 luxで約1万分の1秒未満）で追うイベント画素を混載すれば、**露光中に顔がどちらへどれだけ動いたかの実測軌跡**が残るため、物理計算でピタッとブレを大幅に除去できます。
  - **安くなって普及する理由**: ソニーはすでに2023年学会（VLSI）で3,560万画素RGB＋イベント混載センサーを実証し、スマホ向けでもAlpsenTek（ALPIX-Eiger）がクワッドベイヤーの1/4をイベント画素にした製品を開発済み。2027〜2028年には25〜45万円のミラーレス機へ広がります。
- **参照サイト・根拠（土台になった最新研究・ニュース）**:
  - Prophesee / ソニー IMX636公式仕様＆Mobile Imaging（1,000 lux <100 μs、5 lux <1 ms、モバイルブレ除去下限25 lux）: https://www.prophesee.ai/event-based-sensor-imx636-sony-prophesee/ および https://www.prophesee.ai/event-based-vision-mobile/
  - ソニー VLSI 2023 ＆ AlpsenTek ALPIX-Eiger（`arXiv:2501.19129v1`：実在RGB＋イベント混載センサー実証）: https://www.sony.com/en/SonyInfo/technology/publications/pixel-rgb-hybrid-event-based-vision-sensor-with-pitch-event-pixels-and-up-to-10k-event-frame-rate-by-adaptive-control-on-event-sparsity/ および https://arxiv.org/html/2501.19129v1
  - arXiv（2026年10月、`arXiv:2610.20309`：5 lux暗所でのイベント応答低下とERC帯域制御の実証）: https://arxiv.org/pdf/2610.20309
- **今のカメラとどう違う？（変化・メリット・デメリット・優位性）**:

| くらべる項目 | 2026年のカメラ（RGB専用） | 2028年のカメラ（FH13：RGB＋イベント混載） |
| :--- | :--- | :--- |
| 露光中の動きの記録 | 記録ゼロ（ブレたら修復困難） | 明所〜室内（25 lux〜）でサブミリ秒の軌跡を同時記録 |
| 被写体ブレへの強さ | シャッター速度を上げるしかなく高ISOノイズ増 | 少し遅めのSSでノイズを抑えつつ被写体ブレを大幅除去 |
| 暗闇（5 lux以下）の制約 | 暗所はノイズ増 | 暗所ではイベント画素の反応も約10倍遅くなり効果は限定的 |

  - **何がどう変わる？**: 体育館のバスケや動き回る子どものスナップで、「少し遅めのシャッター速度にして写真を綺麗に保ちながら、動きのブレだけクッキリ抑える」という夢の撮り方ができます。
  - **うれしいメリット**: 普通の60コマ動画から、AIの作り物ではない実測軌跡ベースの超滑らかスローモーション（240〜480コマ相当）を作るのも大得意です。
  - **まだある弱点・注意点（デメリット）**: 光が極端に少ない夜（5 lux以下）ではイベント画素の反応が約10倍遅くなり（~1ミリ秒）ノイズも増えるため、「真っ暗闇でも100%ブレ消滅」とはいきません。また複雑な背景でカメラを大きく振るとイベントデータが溢れやすいため自動間引き制御が必要です。
  - **今のカメラより圧倒的に有利なポイント（優位性）**: 通常の明るさ〜室内撮影において「高ISOノイズ」と「被写体ブレ」の宿敵を同時に大きく減らしてくれる実用性の高い進化です。

### FH14：撮ったあとから流し撮り⇔瞬間静止をスライド選択！「ハイブリッド連続時間収録」
（専門名：高SNRフレーム＋ROI／高照度スパース・イベント＆SPADバースト連続時間収録）
- **ひとことで言うと**: 「1/30秒で流すか、1/10,000秒で止めるか」を撮る前に決めず、**普段の高画質映像＋「動きが激しいエリア（ROI）だけの超高速スパース／SPADバースト記録」**を組み合わせ、**明るい屋外なら撮ったあとからスライダーでシャッター速度や超スロー動画を自在に切り出せる**次世代収録。｜分類 `[願望ブレイクスルー]` ｜到達目安 `2028年秋〜冬`
- **特徴（どんな仕組みで、なぜみんなが買える値段になるの？）**:
  - もし2,400万画素の全画面をずっと毎秒10万コマで記録しようとすると、データ量が毎秒300ギガバイト（映画60本分！）を超えてどんなメモリーカードも一瞬でパンクし、しかも暗い室内では10万分の1秒間に飛んでくる光の粒自体が1粒未満しかなく映像になりません。
  - そこで物理法則とメモリーカード速度（毎秒4〜7 GB）にピタッと合わせるため、**「画面全体は高画質フレーム＋変化差分、水しぶきや鳥の羽など大事なエリア（ROI）や画素を束ねたエリアだけ、十分な光がある屋外で毎秒1万〜10万コマ級の高速SPADバースト収録」**を行うハイブリッド設計を採ります。
  - **安くなって普及する理由**: 2025年のIISW学会で128×128画素・毎秒218万コマの局所バーストSPAD（連続3,000コマ・1 W）が実証され、2024年のインセンサーDVS圧縮（6 mW未満）や2026年の連続時間理論（TDCI）研究も進展。AIが高速領域だけに電力を集中させることで、40〜70万円のクリエイター特化機から登場します。
- **参照サイト・根拠（土台になった最新研究・ニュース）**:
  - IISW 2025（Hua et al.、128×128画素218万fps 31フレームバースト・連続3,000 fps・1 W SPADセンサー、高照度要件も明記）: https://imagesensors.org/Past%20Workshops/2025%20Workshop/2025%20Papers/R09.2_Hua.pdf
  - IEEE *SSCL*（2024年1月、Nair et al.：65nm 3DインセンサーDVSデータ圧縮・<6 mW）: https://experts.umn.edu/en/publications/3-d-in-sensor-computing-for-real-time-dvs-data-compression-65-nm-

- **今のカメラとどう違う？（変化・メリット・デメリット・優位性）**:

| くらべる項目 | 2026年のカメラ（シャッター速度固定） | 2028年のカメラ（FH14：ROI連続時間バースト） |
| :--- | :--- | :--- |
| 撮影後の流し撮り⇔静止変更 | 絶対にやり直し不可 | 編集画面のスライダーで流し撮りもピタッと静止も後から選択 |
| 超スロー動画の切り出し | 事前に画質を落として専用モード必須 | **光量十分な屋外＋ROI／ビニング領域**で1万〜10万fps抽出 |
| 暗い室内での超短シャッター | 光が足りず真っ暗 | 物理的に光の粒が足りないため、暗所では長めの時間幅へ自動調整 |

  - **何がどう変わる？**: 晴れた日のサーフィン、水風船が割れる瞬間、野鳥が飛び立つ羽ばたきを普通に撮るだけで、あとから「芸術的な流し撮り写真」と「1万分の1秒の静止画・超スロー動画」の両方を楽しめます。
  - **うれしいメリット**: 撮影現場で「シャッター速度の選択を間違えた！」という後悔が大きく減ります。
  - **まだある弱点・注意点（デメリット）**: 光の粒そのものが足りない暗い部屋や夜では1/10万秒の抽出は物理的に不可能で、明るい屋外や照明下＋局所エリア限定の機能となります。また専用の新しい動画編集ソフト対応と大きなセンサー消費電力の克服がまだ高いハードルです。
  - **今のカメラより圧倒的に有利なポイント（優位性）**: 130年続いた「1秒間に何コマと固定するカメラの枠」を、物理法則の中で初めて解き放つロマン溢れる技術です。

### FH15：歪みゼロ＆全速ストロボ同調を中上位機へ！「3,000万〜5,000万画素万能グローバルシャッター」
（専門名：30〜50MP級フルサイズ・ピクセル並列ADCグローバルシャッター民主化）
- **ひとことで言うと**: 85万円超・2,460万画素のプロ報道機だけの特権だった「絶対に歪まないグローバルシャッター」を、**1画素ごとの縦積みデジタル変換＋高明暗幅化によって「3,000万〜5,000万画素・明暗13.5〜14.5段・30〜45万円」の中上位万能機へ降ろす**技術。｜分類 `[量産民主化]` ｜到達目安 `2027年夏〜2028年冬`
- **特徴（どんな仕組みで、なぜみんなが買える値段になるの？）**:
  - 普通のカメラは画面の上から下へ順番に読み出すため、速く振るゴルフクラブや列車が斜めに歪んで写ります。全画素を一斉にパシャッと記録するグローバルシャッター（2026年現行Sony α9 III：2,460万画素・ベースISO 250・DR 13.0 EV・約85万円）は歪みゼロな反面、高価格と画素数・明暗幅のわずかな妥協が壁でした。
  - 2026年1月、ソニーは*IEEE JSSC*で**2,520万画素（5.94 μm画素）の真下に3 μmピッチで5,000万個以上の銅接合を並べ、画素ごとに14-bit変換する120fps・消費電力わずか1.55 Wの次世代GS**を公表。これをさらに微細化＋デュアルゲイン／LOFICと組み合わせることで、2027〜2028年には**3,000万〜5,000万画素・DR 13.5〜14.5段**の万能グローバルシャッターが完成します。
