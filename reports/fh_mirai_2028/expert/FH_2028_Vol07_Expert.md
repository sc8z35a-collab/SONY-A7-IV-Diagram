## 1. 本企画新設の意図
「Future History MIRAI 2028（略称：FH MIRAI 2028）」は、2026年12月1日から2028年12月1日までの2年間に出現・量産突破・民主化するカメラ関連の未来技術を、物理工学・量産技術・2028年超知能（ASI）加速の観点から体系化する新設コーナーである。

Vol.01〜Vol.06で、センサー・レンズ・時間軸・頭脳・表示操作・電源/冷却/ボディというカメラ中核を物理法則に沿って再構築した。本巻（Vol.07）では、高画素連写や8K/12K動画がもたらすデータ帯域、極地・報道現場の通信リンクバジェット、ディープフェイク時代の光学的真実の証明、大音量〜静寂をカバーする音響、レンズ資産を守る保管科学、そして長寿命モジュラー規格という周辺6技術（`FH37`〜`FH42`）を詳述する。

## 2. まえがき
2025〜2026年は、カメラ周辺インフラの国際規格と実装が大きく前進した。ストレージではCompactFlash Association（CFA）が2025年2月27日にVPG Profile 5.0（VPG800 / VPG1600）を策定し、11月にはNextorageが世界初VPG1600 Type Bカードを発表、半導体側もSamsung 400層V10・SK hynix 375層・Kioxia BiCS10（332層）のハイブリッド接合3D NAND世代へ突入した。通信では2025年12月に3GPP Release 19 NTN（再生型衛星基地局）が安定化し、2026年10月30日にはIntelとBroadcomがWi-Fi 8（802.11bn）のNPCA相互運用デモを成功させた。真正性証明でも2026年5月11日にキヤノンがEMEA報道機関向けC2PA Authenticity Imaging Systemを発表し、ソニーも像面3D深度再撮影対策を含むCamera Authenticity Solutionを展開している。

本巻では、PCIeレーン物理・衛星リンクバジェット・マイク自己ノイズフロア・PEM電気化学反応式まで厳密に検算した6つのエコシステム技術（`FH37`〜`FH42`）を技術者目線で解剖する。

## 4. 導入
2026年時点のカメラ周辺エコシステム（本リポジトリ`cfexpress` 80部品・`mainboard` 120部品・`mic` 75部品・`drybox` 100部品・`mishoe` 75部品相当）は、以下の6つの構造ボトルネックに直面している。

1. **連写バッファ詰まりと12K RAW帯域不足**: CFexpress 4.0（PCIe 4.0：Type A x1実効約1.7 GB/s、Type B x2実効約3.5 GB/s）では高画素高速連写や12K RAW連続書き込みでバッファ詰まりとカード熱スロットリングが起き、突然の電源断で揮発DRAM内データが破損する。
2. **密集競技場の無線干渉と圏外極地の通信断絶**: Wi-Fi 6E/7は密集電波干渉で遅延が跳ね上がり、携帯圏外の山岳・海上・被災地では外付け衛星端末なしに1枚のプロキシすら送信できない。
3. **ディープフェイク時代の真正性標準の断片化と耐量子移行**: 現行C2PAは一部プロ機限定・有償であり、ソニーの像面3D深度再撮影対策も独自検証サイト依存でオープンC2PA標準へ統合されておらず、さらに将来の耐量子暗号（PQC）移行が控える。
4. **振動板MEMSマイクの爆音歪みと遠距離雑音混入**: 既存静電容量MEMSは120〜135 dB SPLで飽和音割れし、望遠先の声だけを雑踏から抜き出せない。
5. **受動的な防湿庫管理**: 従来の防湿庫は湿度表示のみで、ゴム加水分解ガスやカビ繁殖リスク兆候の能動監視・浮遊胞子対策を持たない。
6. **センサー世代交代のたびのボディ丸ごと買い替え**: センサーや用途だけを変えたいのに筐体・EVF・操作系ごと使い捨てる不経済が続いている。

### FH37：400層級CBA 3D NAND＋PCIe 5.0「Type B 7 GB/s（次世代PCIe 6.0 10 GB/s+）CFexpress」＆不揮発STT-MRAM緊急退避キャッシュ
- **メタ情報**: 分類 `[量産民主化]` ｜ 到達目安 `2027 Q3〜2028 Q4` ｜ 民主化想定価格帯 `CFexpress 5.0 2TBカード 2.5〜4.5万円（カメラ内蔵LPDDR6＋STT-MRAM階層）` ｜ 対応既存モード `cfexpress` / `mainboard`
- **特徴**:
  - セルアレイと周辺CMOS回路を別ウェーハで最適製造しCu-Cu直接接合する**CBA／W2W 332〜400層級3D NAND**と、PCIe Gen5（さらに次世代Gen6準備）コントローラを組み合わせた次期CFexpress 5.0世代カード（なお2026年11月時点でCFA公式のCFexpress 5.0仕様は未公表、以下はPCIe物理仕様に基づく標準拡張）。
  - **PCIeレーン数に基づく正確な物理帯域検算**: CFexpressのレーン数は物理形状で厳格に固定されている（**Type A＝1レーン〔x1〕、Type B＝2レーン〔x2〕、Type C＝4レーン〔x4〕**）。PCIe 5.0（32 GT/s, 128b/130b符号化）の片方向ペイロード上限は **3.938 GB/s/レーン** のため、**Type A (x1) のPCIe 5.0実効上限は約3.4〜3.6 GB/s**（8〜10 GB/sは物理不可能！）、**Type B (x2) のPCIe 5.0理論上限は7.88 GB/s・実効約6.8〜7.2 GB/s（想定将来規格VPG3200級）**となる。連続 **10〜14 GB/s** をカメラ用小型形状で達成するには、**PCIe 6.0 x2（Type B：PAM4 64 GT/s、理論15.1 GB/s・実効10〜14 GB/s）**またはPCIe 5.0 x4（Type C）が必要である。
  - **STT-MRAMの現実的ハイブリッド階層（無限連写＋停電保護）**: 商用フラッグシップ単体STT-MRAM（Everspin 1 Gb＝128 MB DDR4）の容量単価・書換耐性（組込みeMRAM約50万回級）・書込電力を踏まえ、大容量DRAMを丸ごと置換するのではなく**「高速大容量LPDDR6メインバッファ（8〜16 GB）＋不揮発STT-MRAM（128〜512 MB級のファイルシステム・ジャーナル／直前重要フレーム緊急退避キャッシュ）」**の2階層構成を採用。Type Bの約7 GB/s（次世代10 GB/s+）連続書込と合わせ、実写連写の息切れをほぼ解消しつつ突然のバッテリー脱落でもファイル破損・直前コマ消失を防ぐ。
  - **量産民主化メカニズム**: **Samsung（400層V10＋900層450L×2 R&D試作）**、**SK hynix（複雑性回避で375層へ最適化したモリブデン配線ハイブリッド接合、2027年300層超量産目標）**、**Kioxia（BiCS10：332層CBA、2026年夏サンプル出荷）**の3大メーカーが2026〜2027年にかけて高積層量産へ突入。CFAも**2025年2月27日にVPG Profile 5.0（VPG800 / VPG1600）を策定**し、**2025年11月にNextorageが世界初VPG1600 Type Bカードを発表**済み。STT-MRAM市場も2026年にMRAMシェア52.0%（市場10.76億USD）を占め成長中である。
  - **2028年超知能加速の寄与**: ASIによるLDPCニューラル誤り訂正と動的サーマル予測制御により、Type Bカード連続書込時のコントローラ発熱（5〜8 W級）とスロットリングを抑え込む。

### FH38：Wi-Fi 8（802.11bn）会場1秒RAW同期＋3GPP Rel-19低軌道衛星（NTN）極地プロキシ数秒即時発信
- **メタ情報**: 分類 `[量産民主化]` ｜ 到達目安 `2028 Q2〜2028 Q4（Rel-19は2027〜2028、Wi-Fi 8は2028年後半）` ｜ 民主化想定価格帯 `25〜55万円（報道・ネイチャー・全ハイブリッド機内蔵）` ｜ 対応既存モード `mainboard` / `mishoe`
- **特徴**:
  - **地上超高速（Wi-Fi 8）と衛星圏外カバー（3GPP Rel-19 NR-NTN）の正確なリンクバジェット役割分担**により、都会の密集スタジアムから地球上のあらゆる携帯圏外極地までを単一カメラで繋ぐハイブリッド通信モジュール（トップカバー非金属樹脂窓に内蔵したマルチバンド＋L/Sバンド用セラミック／パッチアンテナを使用；なおL/Sバンド1.5〜2.2 GHzの波長は14〜20 cmのためカメラ上面へ多素子フェーズドアレイは物理的に入らず単一無指向〜低利得アンテナ構成となる）。
  - **【地上・密集会場】Wi-Fi 8（IEEE 802.11bn：UHR超高信頼）**: 2×2クライアント実効**2.8〜4.5 Gbps（350〜560 MB/s）**により、100MP圧縮RAW（100〜200 MB）を**有線LAN不要で1秒未満にサーバーへ即時同期**。2026年10月30日にIntelとBroadcomがNPCA（非プライマリチャネルアクセス）相互運用デモで2AP干渉下スループット+30%・遅延−50%を実証（なお協調空間再利用Co-SRは今後検証、最終規格承認は2028年3月予定）。
  - **【極地・圏外】3GPP Release 19 NR-NTN（再生型衛星基地局）**: リンクバジェット検算上、カメラ小型内蔵アンテナ（Class 3：23 dBm / 0.2 W、~0 dBi）と高度600 km低軌道衛星（自由空間＋大気損失157〜164 dB）を結ぶ直接通信の**上り（Uplink）実効スループットは数Mbps〜ピーク10〜20 Mbps級**である（仮に10 Mbpsでも100 MB RAW送信には約80秒を要し「1秒RAW同期」は物理的に不可能）。ゆえに圏外の山頂・海上・被災地では、**①AIセマンティック圧縮プロキシ（数百KB〜2 MB）・C2PA署名・位置情報・SOS（Iridium等のNB-IoT NTN枠含む）を数秒〜十数秒で即時発信**し、**②編集部が選んだ厳選フルRAWのみをバックグラウンド数十秒〜数分で衛星転送**する2段階同期を行う。
  - **量産民主化メカニズム**: 3GPP Release 19は2025年9月機能凍結・12月プロトコル安定化を完了し、GSA（2026年5月）報告で101カ国・275件のキャリア・衛星提携（うち21件D2D商用開始：Starlink Direct-to-Cell、AST SpaceMobile等）が進行中。スマホ向け5G/NTNモデムと2028年後半のWi-Fi 8クライアントチップをそのままカメラ基板へ流用できるため、部材追加コストは15〜30 USD帯へ低下する。
  - **2028年超知能加速の寄与**: カメラ内AIが100枚の連写からベスト3枚を自動選別し、衛星回線（数Mbps）に合わせて人物顔・文字だけ高精細保持するセマンティック適応圧縮（数百KB〜1 MB）を施すことで、極細の衛星回線でも圧倒的な報道即応性を引き出す。
